# PDSA — Programming, Data Structures and Algorithms (Sep 2026)

Graded Programming Assignment (GRPA) solutions for the **PDSA** course.

## Repository Structure

| File | Week | Problem |
|------|------|---------|
| `grpa1_w1.py` | Week 1 | Minimum Difference among P elements |
| `grpa 2_w1.py` | Week 1 | Goldbach's Conjecture |
| `grpa2_w2.py` | Week 2 | Largest element in a sorted-rotated list (Binary Search) |
| `grpa3_w2.py` | Week 2 | Merge two sorted arrays in place |

## Topics Covered

- **Week 1** — Sorting, Sliding Window, Number Theory (Prime Testing)
- **Week 2** — Binary Search, In-Place Merge with Constrained Operations

## How to Run

```bash
python <filename>.py
```

> **Python 3.10+** is recommended.
